> **ℹ️ About this page.** The template for one research note: what one participant told us, or what we saw, in a single session about how the *piquete* is composed. Notes are the raw evidence behind deliverable #3 (Assignment §5.3, §7.1.2 #3); the team cites them by ID on **Research Synthesis and Decisions**, **01 · Problem and Opportunity** and **Personas**.

> **ℹ️ Guidance.** One page per session, created as a child of **03 · User Research** from this template (register it as a Confluence space template so it appears under *Create*). Title: `<Code> · YYYY-MM-DD · <Method>`, e.g. `B-01 · 2026-10-10 · Interview`. Write the note the same day from the note-taker's notes, with codes only, never names, and no recordings. For observation sessions, the timed events go on **Observation Grid** and this note holds the rest.

> **⚠️ Rule.** Never fabricate or complete participant answers. If nobody said it, it is not in the note (Assignment §5.3, §11).
