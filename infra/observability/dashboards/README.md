# Grafana dashboards

Dashboards kept in Git as JSON (SCRUM-97). Grafana loads every file here, in Docker Compose (profile
`observability`, `infra/observability/grafana-dashboards.yaml`) and in Kubernetes (the `grafana-dashboards`
ConfigMap, generated by `infra/k8s/observability/kustomization.yaml` from the copy in
`infra/k8s/observability/grafana/dashboards/`, because kustomize reads only files under its own folder; the test
TC-SCRUM-97-10 fails if the copy and the file here differ). They are read-only in Grafana: change
the JSON here and deploy.
